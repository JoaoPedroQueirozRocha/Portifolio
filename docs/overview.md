# Portfolio & Media Tracker — Visão Geral

**Versão:** 1.0  
**Data:** Junho 2025

## O que é

Portfolio pessoal de desenvolvedor Full Stack com sistema integrado de rastreamento de mídia (livros, filmes, séries e animes), blog técnico e servidor MCP para integração com Claude.

**Objetivo:** demonstrar habilidade técnica real através de uma aplicação que o próprio autor usa no dia a dia, combinando portfolio profissional com utilidade prática.

## Módulos

| Módulo | Descrição | Visibilidade |
|--------|-----------|--------------|
| Portfolio | Apresentação pessoal, skills, projetos em destaque | Público |
| Media Tracker | Catálogo de livros, filmes, séries e animes | Público |
| Blog | Posts técnicos com editor Markdown | Público |
| Stats | Dashboard visual de consumo de mídia | Público |
| Admin Panel | CMS próprio para gerenciar todo o conteúdo | Privado |
| MCP Server | Servidor para integração com Claude | Privado |

## Repositórios

- `portfolio-frontend/` — Next.js 14
- `portfolio-backend/` — Node.js + Fastify (inclui MCP Server)
